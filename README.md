Hyperbola Community Edition is an open-source student management system designed to facilitate online education and course management. It provides a platform for private educators to create, manage, and deliver courses to students in a structured and interactive manner.

> THIS REPOSITORY IS A WORK IN PROGRESS AND IS **NOT** PRODUCTION-READY.

## Features

- **Course Management**: Create and organize courses with modules, lessons, and assignments.
- **Student Enrollment**: Manage student registrations and track their progress.
- **Routine Scheduling**: Set up class schedules and routines for different courses.
- **User Authentication**: Secure login and registration system for educators under one group.
- **Responsive Design**: Accessible on various devices including desktops, tablets, and smartphones.

## Technology Stack

- **Frontend**: Next.js with TypeScript, Tailwind CSS, and ShadCN UI components.
- **Backend**: Node.js with Drizzle ORM for database interactions.
- **Database**: PostgreSQL for data storage.
- **Authentication**: BetterAuth for secure user authentication.
- **Build Tool**: Bun for running and building the application.
